# 📱 Android Todo App (Kotlin & Room Database)

A feature-rich, native Android task management application built using **Kotlin** and modern Android development practices. Designed with a clean **Material Design** interface, the application provides an offline-first experience for managing tasks, setting priorities, and organizing daily productivity workflows.

---

## ✨ Features

- **Task Management**: Create, edit, mark complete, and delete tasks seamlessly.
- **Priority & Reminders**: Categorize tasks by priority levels and set reminders to stay on schedule.
- **Offline-First Storage**: Powered by **Room Database** for fast, reliable local persistence without requiring an active network connection.
- **Modern UI/UX**: Built following **Material Design** principles for an intuitive, responsive user experience.
- **Lifecycle-Aware**: Efficient state management and lifecycle handling to prevent memory leaks and data loss during configuration changes (e.g., screen rotation).

---

## 🛠️ Tech Stack & Architecture

- **Language**: [Kotlin](https://kotlinlang.org/)
- **IDE**: [Android Studio](https://developer.android.com/studio)
- **Local Database**: [Room Persistence Library](https://developer.android.com/training/data-storage/room)
- **Architecture**: MVVM / Android Architecture Components
- **UI Framework**: Material Design Components (XML / Layouts)
- **Asynchronous Operations**: Coroutines / LiveData / StateFlow
